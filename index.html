Overview

Protecting privacy in motion data

PMR transfers motion from an original skeleton to a “dummy” skeleton, masking personally identifiable information while keeping actions recognizable.

Privacy Protection

Reduces re-identification risk from 87.8% to 7.8% by masking PII like body shape, gait patterns, and limb lengths.

Action Preservation

Maintains 35.7% action recognition accuracy, significantly outperforming baseline anonymization methods (2–3%).

Motion Retargeting

Transfers motion from original to dummy skeleton, replacing identity while preserving movement semantics.

Adversarial Learning

Cooperative and adversarial training disentangles identity from motion without prior knowledge of attack models.

Fast Inference

Processes 75 frames (~2.5s of motion) in 0.006 seconds, enabling real-time anonymization applications.

Robust Evaluation

Tested on NTU RGB+D 60 and 120 datasets with comprehensive privacy and utility metrics.

Architecture

Two-encoder, one-decoder

A cooperative-adversarial paradigm that disentangles motion from identity through dual encoders and specialized classifiers.

EM

Motion Encoder

4-layer CNN with reflection padding. Extracts action-specific temporal information into a 256×32 embedding.

EP

Privacy Encoder

Identical architecture. Captures skeleton structure and style (PII) into a 256×32 privacy embedding.

D

Decoder

4-layer transpose CNN with upsampling. Reconstructs skeletons from concatenated embeddings (512×32).

M

Motion Classifier

Predicts action from embeddings. Cooperative with EM, adversarial with EP. 60 or 120 classes.

P

Privacy Classifier

Predicts actor identity. Cooperative with EP, adversarial with EM. 40 or 106 classes.

Q

Quality Controller

GAN-style discriminator. Distinguishes real vs. generated skeletons to ensure visual plausibility.

Getting Started

Quick start guide

Install, train, evaluate, and integrate PMR into your projects.

# Clone the repository
git clone https://github.com/Thomasc33/Privacy-Retargeting.git
cd Privacy-Retargeting

# Create virtual environment
python -m venv venv
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

Requirements

Python 3.8+

Modern Python with type hints

PyTorch 2.0+

Deep learning with CUDA support

CUDA 11.8+

GPU acceleration (recommended)

# Basic training on NTU-60
python cli.py train --dataset ntu60 --model pmr

# Training with custom parameters
python cli.py train \
    --dataset ntu60 \
    --model pmr \
    --batch-size 32 \
    --lr 1e-5 \
    --device cuda:0 \
    --checkpoint-dir checkpoints \
    --use-mlflow

# Training on NTU-120
python cli.py train --dataset ntu120 --model pmr

# Training DMR baseline
python cli.py train --dataset ntu60 --model dmr

4 stages, ~295 epochs total. Training time: ~6.5 hours on NVIDIA RTX 3090.

# Evaluate trained model
python cli.py evaluate \
    --model-path checkpoints/pmr_best.pt \
    --dataset ntu60 \
    --output results.json

# Anonymize a skeleton sequence
python cli.py anonymize \
    --model-path checkpoints/pmr_best.pt \
    --input data/sample.pkl \
    --output data/anonymized.pkl

# Visualize results
python cli.py visualize \
    --input data/anonymized.pkl \
    --output video.gif

# Create comparison video
python cli.py compare \
    --original data/sample.pkl \
    --anonymized data/anonymized.pkl \
    --output comparison.gif
from models.pmr import PMRModel
import torch

# Load model
model = PMRModel(T=75, encoded_channels=(256, 32))
checkpoint = torch.load('checkpoints/pmr_best.pt')
model.load_state_dict(checkpoint['model_state_dict'])
model.eval()

# Anonymize skeleton
original = torch.randn(1, 75, 25, 3)  # (batch, frames, joints, coords)
dummy = torch.randn(1, 75, 25, 3)

with torch.no_grad():
    anonymized = model.cross_reconstruct(original, dummy)

# Get embeddings for analysis
motion_emb, privacy_emb = model.get_embeddings(original)

print(f"Motion embedding: {motion_emb.shape}")
print(f"Privacy embedding: {privacy_emb.shape}")
print(f"Anonymized skeleton: {anonymized.shape}")

Implementation specifications

Technical specifications from the paper.

Hardware

GPU: NVIDIA RTX 3090 (24GB)
Training: ~6.5 hours
Inference: 0.006s per sequence

Framework

Deep Learning: PyTorch 2.0+
Optimization: Adam optimizer
Learning Rate: 1e-5

Data

Datasets: NTU RGB+D 60/120
Sequence: 75 frames
Joints: 25 per skeleton

Architecture

Encoders: 4-layer CNN
Decoder: 4-layer Transpose CNN
Embedding: 256 × 32
